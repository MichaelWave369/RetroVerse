# Third-party components and media

RetroVerse's application code is MIT-licensed. The following components retain their independent licenses:

- [zip.js](https://github.com/gildas-lormeau/zip.js), BSD-3-Clause, Copyright (c) 2023 Gildas Lormeau. Used locally to build and read portable Game Vault ZIP backups. See upstream LICENSE for source and conditions; this dependency retains its license independently of RetroVerse MIT code.
- [Tandy/MS-DOS/DeskMate historic media](https://archive.org/details/Tandy1000SL2Disks): linked only for historical research. RetroVerse contains no Tandy ROM, Microsoft DOS 3.3, DeskMate application disks or copyrighted Tandy images. The Internet Archive item's Public Domain tag is uploader-supplied metadata, not independent evidence of the underlying software's legal status. The Rung 8 workstation uses the already-disclosed GPL js-dos emulator and locally extracted user-provided disk files.
- [v86](https://github.com/copy/v86), BSD-2-Clause. Installed via the official npm package and built into the application.
- [SeaBIOS](https://www.seabios.org/) BIOS firmware and VGA BIOS from the v86 upstream repository, LGPL. Downloaded at build time from pinned upstream commit 315b2b0b758703ef0e6cc7b4088d6068f83f3c20. See [v86 bios/COPYING.LESSER](https://github.com/copy/v86/blob/master/bios/COPYING.LESSER) and the upstream source to obtain firmware source and license terms.
- [js-dos v8](https://js-dos.com/), GPL-2.0. Browser game-cabinet player and its emulator runtimes are loaded from the js-dos upstream CDN at runtime, rather than redistributed in our repository. See upstream source and its license requirements. The documented Digger example is linked from that upstream service, and no game files are repackaged.
- [Scripted Amiga Emulator](https://github.com/naTmeg/ScriptedAmigaEmulator), GPL-2.0-or-later, by Rupert Hausberger and upstream contributors. Bundled separately as its unmodified example webpage plus complete SAE JavaScript sources at `/amiga/`, pinned to commit `8ebce7b8beb9ebe243e5ea7b5150b3f16f665303`. The published folder includes `gpl.htm`, `readme.htm` and `SOURCE-PROVENANCE.txt`. SAE remains licensed under the GPL; RetroVerse React code is independently MIT-licensed. No ROMs or game images are provided.
- [ScummVM](https://www.scummvm.org/) and [unofficial ScummVM Web Demo](https://github.com/chkuendig/scummvm-demo): the Rung 4 adventure room links to or optionally embeds the separately hosted third-party WebAssembly player at `scummvm.kuendig.io`. RetroVerse does **not** build, bundle, redistribute or claim ownership of ScummVM or its games. ScummVM is GPL-licensed and the player/operator retain their own license and privacy obligations. Accessing the external player may involve third-party network, storage, login or browser cookies. The game index is metadata only; cataloging a game does not grant distribution rights. Freeware entries link to the official [ScummVM Games](https://www.scummvm.org/games/) download archive.
- [FreeDOS](https://freedos.org/), free/open DOS-compatible operating system. The 720 KiB bootable floppy is copied at build time from [the archived copy/images repository](https://github.com/copy/images/blob/db92d8fd4a53dbd73b8e0588bb4bd8fe37a1975a/freedos722.img) (git blob ec7a4cf9fc9a30adbc83c5b4755c637568a74d9a), verified by Git object SHA-1 and size, then served from this site's own /media directory. The image contains multiple FreeDOS-era programs, each with its own copyright and licensing terms. Source and licensing details for the OS are available at [freedos.org](https://freedos.org/) and the [copy/images documentation](https://github.com/copy/images). No proprietary Microsoft media is included.

No Microsoft DOS or commercial game images are included. You must own or be authorized to use any ROM, firmware, disk, or game files that you provide. Booting in a browser does not make copyrighted software public-domain.
