# RetroVerse

**A browser-based time machine for classic personal computers.**

RetroVerse is an open, local-first collection of real emulated machines, starting with an IBM PC-compatible DOS experience powered by [v86](https://github.com/copy/v86). Future stations will add Commodore Amiga and ScummVM-powered adventure games.

## Project principles

- Authentic emulation instead of a fake terminal.
- User-provided operating-system and game media stay local to the browser.
- Free and openly distributable boot options first.
- Attribution and compliance for emulator and firmware dependencies.
- A responsive React interface hosted on GitHub Pages without a paid server.

## Status

Initial project foundation. The DOS emulator implementation is being developed in a separate pull request.
